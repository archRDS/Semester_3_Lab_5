# Лабораторная работа №5. Вариант 11

Торговая площадка с консольным меню. Для сборки нужен CMake от 3.20 и компилятор с поддержкой C++17. Внешние библиотеки приложения не требуются.

## Сборка и запуск

В PowerShell из папки проекта с Visual Studio и компонентом «Разработка классических приложений на C++» выполните:

```powershell
cmake -S . -B build
cmake --build build --config Release
.\build\Release\Marketplace.exe
```

Для MinGW-w64 с `g++` и `ninja` в `PATH`:

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
.\build\Marketplace.exe
```

## Пример работы

После ввода номера команды нажмите Enter.

1. В меню введите `1` и добавьте продавца «Анна». Программа выдаст номер `1`.
2. Введите `2` и добавьте покупателя «Иван» с балансом `1500` руб. Программа выдаст номер `2`.
3. Введите `3`, выберите продавца `1` и выставьте товар «Блокнот» по `179,90` руб. в количестве `5` шт.
4. Введите `5`, затем номер покупателя `2`, номер товара `1`, количество `2` и способ оплаты `2` (банковская карта).
5. В чеке появятся сумма `359,80` руб. и баланс `1140,20` руб. По команде `4` можно проверить, что в каталоге осталось `3` блокнота.
6. Введите `0` для выхода.

Все три способа оплаты используют баланс покупателя в рублях. Участники, товары и их остатки хранятся в памяти до завершения программы.
